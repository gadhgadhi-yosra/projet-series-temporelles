# Annexe — restitution LLM et traçabilité

Date de cette restitution : 9 octobre 2026.

**Provenance réelle.** Les prompts ont été formulés par l'assistant pour exécuter la demande de l'étudiante « compléter toutes mes tâches ». Les réponses ont été rédigées par l'assistant Codex dans cette même session, puis enregistrées intégralement dans les fichiers ci-dessous. Il ne s'agit pas d'appels à une API LLM externe, de conversations avec deux modèles différents, ni d'une évaluation indépendante. La version exacte du modèle n'est pas enregistrée dans ce journal. Le contexte antérieur de la conversation était également accessible à l'assistant ; les prompts seuls ne constituent donc pas une transcription intégrale de toute la session.

L'étudiante a répondu : « Non, je n’en ai pas encore rédigé. » à la question sur l'existence d'une analyse personnelle antérieure. Aucun texte n'est attribué à une telle analyse.

## Fichiers conservés sans résumé des réponses

1. `contexte_resultats.json` : faits calculés transmis à la restitution.
2. `01_prompt_vulgarisation.txt` : prompt exact et données incluses.
3. `01_reponse_integrale.md` : texte intégral produit pour la vulgarisation.
4. `02_prompt_recommandations.txt` : prompt exact, contexte et première réponse inclus.
5. `02_reponse_integrale.md` : texte intégral produit pour les recommandations.
6. `audit_affirmations.csv` : contrôle des affirmations et de leurs preuves.
7. `manifest.json` : provenance déclarée et empreintes des fichiers du journal.

Les réponses archivées ne doivent pas être modifiées silencieusement : toute correction ultérieure doit être ajoutée dans un fichier distinct. Les résultats sont ceux des exports associés à ce journal. Si les calculs sont relancés avec d'autres données ou paramètres, il faut refaire l'annexe et conserver la version précédente.

## Limite méthodologique

La comparaison avec une analyse humaine antérieure demandée dans le sujet n'est pas réalisable rétroactivement. L'annexe fournit une restitution assistée et un contrôle factuel par l'assistant. Elle ne remplace pas la réflexion personnelle de l'étudiante ni une vérification indépendante.
